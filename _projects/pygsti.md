At Sandia, I contribute to [pyGSTi](https://github.com/sandialabs/pyGSTi), an open-source Python package for modeling and characterizing noisy quantum information processors. Its core capabilities include gate set tomography, randomized benchmarking, and robust phase estimation.

Documentation: <https://pygsti.readthedocs.io/>.
